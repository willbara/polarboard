## Lists

- Press `Enter` at the end of an item to start the next one
- `Tab` indents an item, `Shift Tab` brings it back
  - Like this one
    - And this one
- `Enter` on an empty item ends the list

1. Numbered lists count by themselves
2. Start a line with `1.` and keep going
3. The numbers don't even need to be right

Inside a table, `Tab` and `Shift Tab` move between cells and line the columns up as you go. `Enter` at the end of a row adds a row, and `Ctrl Shift L` tidies the whole table.

The colons in the second row set each column's alignment: `:---` left, `:---:` centered, `---:` right.
