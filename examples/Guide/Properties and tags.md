## Properties

The small panel above this note shows its **properties**: a status, a number, a date, a yes/no value and a list of tags. They're saved as standard front matter at the top of the file, so other apps like Obsidian read them too.

Add properties from the note's menu (`⋯`), the command palette, or `/properties`. Notes without any don't show the panel at all.

Two properties mean something to Polarboard:

- `tags` adds tags to the note, like the #tags written in the text.
- `spellcheck: false` turns writing checks off for that note, as [[Frases em português]] does.

## Tags

Write a tag anywhere with `#`: #ideas, #reading, #someday. Typing `#` suggests the tags you already use.

- **Nested tags** use a slash: #project/garden and #project/travel both count as #project.
- **Folder tags:** right-click a folder → **Tags for every note in here**. Every note in the **Projects** folder has the #project tag this way, without writing it.
- The **Tags** panel (`#` at the top of the sidebar) lists every tag with a count. Click one to see its notes.
- Search with `tag:project` to find them all, nested ones included.

Tags in code, like `#not-a-tag`, are ignored.
