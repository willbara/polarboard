Every shortcut can be changed in **Settings → Hotkeys**. On a Mac, `Ctrl` is `⌘`.

## Moving around

| Keys | Does |
| :--- | :--- |
| `Ctrl O` | Open a note by name |
| `Ctrl P` | Search inside notes |
| `Ctrl Shift P` | Command palette: every action, by name |
| `Ctrl \` | Show or hide the sidebar |
| `Alt T` / `Alt W` | New tab / close tab |
| `Ctrl Alt O` | Open a note to the side |

## Writing

| Keys | Does |
| :--- | :--- |
| `Alt N` | New note |
| `Alt D` | Today's daily note |
| `Alt Shift T` | Insert a template |
| `Ctrl B` / `Ctrl I` / `Ctrl K` | Bold / italic / link |
| `Ctrl E` | Switch between writing and reading |
| `Ctrl F` / `Ctrl H` | Find / find and replace |
| `Ctrl Shift L` | Tidy the table under the cursor |
| `F8` | Next writing suggestion |
| `Ctrl Shift F` | Focus mode |

## Notes

| Keys | Does |
| :--- | :--- |
| `Alt S` | Add or remove a star |
| `Alt H` | Version history |
| `Ctrl S` | Save and sync now |

In the sidebar, the arrow keys move and open folders, `Enter` opens, `F2` renames, `Delete` deletes and `Shift F10` opens the menu.

> [!tip] Using Firefox?
> Firefox keeps `Ctrl Shift P` for itself. Give the command palette another key in **Settings → Hotkeys**.
